# 🚢 Titanic Survival Analysis - Excel Project

## 📌 Project Overview
This project analyzes the famous Titanic dataset using Microsoft Excel to explore the key factors that influenced passenger survival.  
The goal is to extract meaningful insights from the data and understand patterns related to survival rates.

---

## 📊 Objectives
- Analyze survival rate based on gender
- Explore survival rate across passenger classes
- Investigate the impact of age on survival
- Study the effect of family size on survival
- Perform data cleaning and handling missing values

---

## 🛠️ Tools & Techniques Used
- Microsoft Excel
- Data Cleaning & Preparation
- Pivot Tables
- Pivot Charts
- Slicers
- Exploratory Data Analysis (EDA)

---

## 📈 Key Insights
- Female passengers had a higher survival rate compared to males
- First-class passengers had better survival chances than other classes
- Younger passengers had a relatively higher survival probability
- Family size played a role in survival likelihood

---


## 📁 Dataset
The dataset used in this project is the Titanic dataset, which contains information about passengers such as age, gender, class, and survival status.
